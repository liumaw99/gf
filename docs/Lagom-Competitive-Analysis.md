# Lagom 竞品深度分析

> 分析维度：功能、体验、商业模式、AI 能力、用户粘性  
> 数据来源：应用商店、用户评论、行业报告、产品实测

---

## 一、直接竞品分析

### 1.1 番茄ToDo

| 维度 | 详情 |
|------|------|
| **定位** | 学霸必备的番茄钟+待办+自习室 |
| **核心功能** | 番茄钟计时、待办清单、自习室（多人虚拟教室）、数据统计、学霸模式（锁机） |
| **AI 能力** | ❌ 无 AI 功能 |
| **优势** | 无广告秒启动、自习室社交氛围好、数据统计完善、用户基数大 |
| **劣势** | 功能同质化严重、无情感连接、AI 能力为零、自习室排名制造焦虑 |
| **商业模式** | VIP 季度卡（去广告+更多功能），iOS 日均收入 ~$1,559 |
| **用户画像** | 学生为主，尤其是备考群体 |
| **下载量** | iOS/Android 累计千万级 |

**用户评价关键词**：
- 正面："自习室很有氛围"、"数据统计很详细"、"没有广告"
- 负面："打卡像完成任务"、"断一天就不想再打开"、"没有温度"

**Lagom 差异化策略**：不做"工具"做"伙伴"，用 AI 对话替代冷冰冰的打卡界面。

---

### 1.2 Forest（专注森林）

| 维度 | 详情 |
|------|------|
| **定位** | 种树专注，远离手机 |
| **核心功能** | 种树专注（离开App树会枯）、白名单、好友种树、真实树木种植 |
| **AI 能力** | ❌ 无 AI 功能 |
| **优势** | 游戏化种树成就感强、种植真树满足公益心理、界面简洁 |
| **劣势** | 付费下载（iOS $1.99）、社交功能弱（仅现实好友）、功能单一、无习惯养成 |
| **商业模式** | 付费下载 + 内购树种 |
| **用户画像** | 愿意为专注付费的中高端用户 |
| **下载量** | 累计千万级，但被番茄ToDo超越 |

**用户评价关键词**：
- 正面："看到自己种的森林很有成就感"、"真的能帮助放下手机"
- 负面："树种太贵了"、"种完树就没有动力继续了"、"没有习惯追踪"

**Lagom 差异化策略**：Forest 的"树"是静态的，Lagom 的"伙伴"是动态成长的、会说话的、理解你的。

---

### 1.3 Habitica

| 维度 | 详情 |
|------|------|
| **定位** | RPG 游戏化习惯养成 |
| **核心功能** | 任务=打怪、完成=升级、组队=公会、失败=掉血 |
| **AI 能力** | ❌ 无 AI 功能 |
| **优势** | 游戏化深度极高、社交互动丰富（组队打Boss）、社区活跃 |
| **劣势** | 学习成本极高、界面复古（像2000年代网页游戏）、对非游戏玩家不友好 |
| **商业模式** | 订阅制 + 宝石内购 |
| **用户画像** | 核心游戏玩家、喜欢RPG的用户 |
| **下载量** | 小众，百万级 |

**用户评价关键词**：
- 正面："像玩游戏一样养成习惯"、"和朋友组队很有动力"
- 负面："太复杂了"、"界面好丑"、"不是游戏玩家真的用不下去"

**Lagom 差异化策略**：游戏化要"轻"——不需要学习规则，你的真实行动自然驱动伙伴成长。

### 1.4 Streaks

| 维度 | 详情 |
|------|------|
| **定位** | 极简习惯追踪 |
| **核心功能** | 每日6个习惯、HealthKit 自动同步、极简圆环进度、iOS 小组件 |
| **AI 能力** | ❌ 无 AI 功能 |
| **优势** | 界面极简美观、HealthKit 联动、Apple Design Award 获奖 |
| **劣势** | 功能单一（仅追踪）、无社交、无分析洞察、仅 iOS |
| **商业模式** | 一次性付费 $4.99 |
| **用户画像** | Apple 生态重度用户、极简主义爱好者 |
| **下载量** | 中高端用户群体 |

**用户评价关键词**：
- 正面："最美的习惯App"、"和Apple Watch配合完美"
- 负面："只有6个习惯不够用"、"断了streak很打击人"、"没有为什么失败的分析"

**Lagom 差异化策略**：不追求"极简到没有功能"，而是"温暖到有温度"——失败时理解你，而非归零。

### 1.5 YoYo日常

| 维度 | 详情 |
|------|------|
| **定位** | 陪伴式打卡习惯养成 |
| **核心功能** | 卡通伙伴（YoYo）、习惯打卡、专注计时、心情日记 |
| **AI 能力** | ⚠️ 极低（预设回复，无真正AI） |
| **优势** | 角色陪伴感较好、界面可爱、有玫瑰花成长机制 |
| **劣势** | AI 智能化程度极低、伙伴不会真正"对话"、功能堆砌感强 |
| **商业模式** | VIP 会员（解锁更多装扮和功能） |
| **用户画像** | 年轻女性用户为主 |
| **下载量** | 119万+ |

**用户评价关键词**：
- 正面："YoYo好可爱"、"有人陪的感觉"
- 负面："回复太机械了"、"像个花瓶"、"功能多但都不精"

**Lagom 差异化策略**：YoYo 是"看起来有陪伴"，Lagom 是"真的有陪伴"——基于大模型的真实对话能力。

---

### 1.6 Momo（新兴竞品，需高度关注）

| 维度 | 详情 |
|------|------|
| **定位** | AI 宠物 + 自律习惯养成 |
| **核心功能** | AI 宠物 Momo、对话式习惯建议、每日反思、睡眠追踪、自我关怀 |
| **AI 能力** | ✅ 基于 LLM 的真实对话 |
| **优势** | a16z 领投 $250万 验证模式、情感陪伴+自律的品类创新、对话质量高 |
| **劣势** | 仅 iOS、未进入中国、游戏化奖励可能空洞化 |
| **商业模式** | 免费+内购（装扮宠物） |
| **用户画像** | 寻求情感陪伴的年轻用户 |
| **下载量** | 新兴，用户创建超 200 万个任务 |

**关键洞察**：Momo 验证了"AI 陪伴 + 自律"赛道的可行性。Lagom 需要在以下方面超越：
1. **更早进入中国市场**
2. **更深度的习惯科学**（不只是对话，而是真正基于行为心理学的习惯引擎）
3. **更可持续的游戏化**（避免"刷金币"空洞感）
4. **端侧隐私保护**（Momo 是云端 AI）

## 二、间接竞品分析

### 2.1 ChatGPT / 豆包 / Kimi（通用 AI 助手）

| 维度 | 分析 |
|------|------|
| **威胁程度** | 中等 |
| **分析** | 用户可以问 AI"帮我制定运动计划"，但：① 没有追踪执行的功能 ② 没有情感陪伴的持续交互 ③ 没有游戏化反馈 ④ 对话历史不关联习惯进度 |
| **Lagom 优势** | 专用场景的深度整合：目标→计划→执行→反馈→调整的完整闭环 |

### 2.2 Notion / 滴答清单（效率工具）

| 维度 | 分析 |
|------|------|
| **威胁程度** | 低 |
| **分析** | 这些工具解决"管理任务"，不解决"坚持执行"。用户用 Notion 做了完美计划，但三天后就忘了打开。 |
| **Lagom 优势** | 主动提醒、情感连接、降低执行门槛——解决"最后一公里"问题 |

### 2.3 Calm / Headspace（冥想/心理健康）

| 维度 | 分析 |
|------|------|
| **威胁程度** | 低-中 |
| **分析** | 解决"心理健康"问题，但不解决"具体习惯养成"。且内容成本高，需要大量专业音频内容。 |
| **Lagom 优势** | 更聚焦"行动力"而非"放松"，AI 生成内容成本远低于录制音频 |

## 四、竞品定价分析

| 产品 | 免费层 | 付费层 | 付费率估算 |
|------|--------|--------|-----------|
| 番茄ToDo | 大部分功能 | VIP 季度卡 ~¥18 | ~3-5% |
| Forest | 基础树种 | 付费下载 + 树种内购 | 100%下载付费 |
| Habitica | 全部功能 | 订阅 + 宝石 | ~5% |
| Streaks | 无 | 一次性 $4.99 | 100% |
| YoYo日常 | 基础功能 | VIP ~¥12/月 | ~2-4% |
| Momo | 基础功能 | 装扮内购 | 新兴，未知 |
| **Lagom（目标）** | AI对话+3个习惯+本地存储 | $3.99/月 或 $29.99/年 | ~5-8% |

**定价策略洞察**：
- 一次性付费（Streaks/Forest）收入天花板低
- 订阅制是长期最优解，但免费层必须足够好以降低转化门槛
- Lagom 的 AI 对话作为免费层核心功能，建立强粘性后再转化

## 五、竞品用户流失原因总结

基于应用商店评论、社交媒体讨论的归纳：

| 流失原因 | 占比估算 | 典型用户原话 |
|----------|----------|-------------|
| "打卡像完成任务，没有动力" | 35% | "每天打卡只是为了不断签，已经忘了为什么要做" |
| "断签后就不想再打开" | 25% | "连续打卡30天，有一天忘了，瞬间不想继续了" |
| "功能太多太复杂" | 15% | "只想简单记录习惯，结果各种功能看花眼" |
| "没有真正理解我" | 15% | "不管我状态好坏，都是同样的提醒" |
| "担心数据隐私" | 10% | "不想让别人知道我在用自律App，感觉像暴露弱点" |

**Lagom 的针对性设计**：
1. → AI 伙伴的情感连接替代"任务打卡"
2. → 习惯强度指数替代"连续打卡天数"
3. → 极简交互（打开即对话）
4. → 情绪感知动态调整
5. → 默认本地存储+端到端加密

## 六、竞争策略总结

### 6.1 错位竞争
不与番茄ToDo/Forest 在"功能丰富度"上竞争，而是在"情感连接"上建立壁垒。

### 6.2 技术壁垒
端侧 AI + 长期记忆 + 情绪感知算法，形成 6-12 个月的领先窗口。

### 6.3 品牌定位
**Lagom = 自律领域的"AI 伴侣"，而非"效率工具"**
- 对标不是 Todo App，而是"有智能的习惯教练"
- 类比：Lagom 是习惯养成领域的 Duolingo（游戏化学习）+ Replika（AI 陪伴）

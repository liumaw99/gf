## 二、用户画像与需求分析

### 2.1 核心用户画像

**主力用户："间歇性自律患者"**

- 年龄：18-35 岁
- 身份：大学生、研究生、初级职场人、自由职业者
- 特征：
  - 有明确自我提升意愿（想运动、想学习、想早起）
  - 但反复陷入"立志→坚持3天→放弃→自责→再立志"的循环
  - 对现有打卡工具感到厌倦或愧疚
  - 愿意为"真正有效"的解决方案付费

**次级用户：**
- 高压职场人（需要情绪出口和结构化休息）
- ADHD/注意力困难人群（需要外部监督和温和提醒）
- 备考学生（考研、考公、考证，有明确时间目标）

### 2.2 用户旅程与痛点

```
【觉醒期】意识到需要改变
    ↓ 痛点：不知道从何开始，目标太大被吓退

【工具期】下载传统自律 App
    ↓ 痛点：冷冰冰的打卡、失败的负罪感、7天后卸载

【孤独期】独自挣扎
    ↓ 痛点：没有人理解、没有反馈、动力逐渐耗尽

【放弃期】回到原点
    ↓ 痛点：自我否定、"我就是不自律"的标签

【重新觉醒】→ 循环
```

**Lagom 的切入点**：打破这个循环，把"孤独的对抗"变成"有伙伴陪伴的旅程"。

### 2.3 用户深度需求（非表面需求）

| 表面需求 | 深层需求 | Lagom 对应设计 |
|----------|----------|----------------|
| 打卡记录 | 被看见、被认可 | AI 伙伴的积极反馈 |
| 时间管理 | 对生活的掌控感 | 微习惯降低失控焦虑 |
| 戒掉拖延 | 减少自我攻击和愧疚 | 失败时的共情而非惩罚 |
| 提高效率 | 自我价值感提升 | 成长档案可视化进步 |
| 达成目标 | 成为一个"更好的人" | 伙伴成长绑定自我成长 |

## 三、行业趋势与机会

### 3.1 2025 五大确定性趋势

#### 趋势一：从"工具型"到"教练型"
- 用户不再满足于"记录"和"统计"
- 需要的是"理解我、指导我、在我困难时给我力量"
- AI Agent 的自主决策和工具调用能力使"AI 教练"成为可能

#### 趋势二：AI 陪伴赛道爆发
- 美国卫生局局长警告：孤独感正在成为流行病
- 社会层面孤独危机 + LLM 技术突破 = AI 陪伴类 App 需求激增
- Momo（a16z 领投 $250万）验证：AI 宠物+自律习惯是新品类

#### 趋势三：端侧 AI 与隐私优先
- 用户对"我的行为数据被谁看到"越来越敏感
- 端侧 LLM（Gemma、Phi、Qwen 小模型）性能已接近可用
- "数据不出设备"成为差异化卖点

#### 趋势四：多模态交互普及
- 语音成为更自然的交互方式
- 语音合成（TTS）和识别（STT）成本已降到可接受范围
- 情感计算：通过语调判断用户情绪状态

#### 趋势五：微习惯成为主流方法论
- 行为心理学验证："小行动"比"大目标"更有效
- James Clear《原子习惯》全球畅销，理念已被广泛接受
- 用户厌倦了"21天养成习惯"的鸡汤，需要科学方法

### 3.2 中国市场特殊性

| 特点 | 机会 |
|------|------|
| 大模型 API 成本极低（DeepSeek、Qwen 价格低于 GPT 数十倍） | AI 对话功能可持续运营 |
| 微信生态庞大 | 未来可考虑微信小程序版本 |
| 年轻用户偏好"陪伴感"（乙女游戏、虚拟偶像市场庞大） | AI 伙伴的情感化设计有用户基础 |
| 国内尚无头部 AI 自律 App | 市场空白，先发优势明显 |

## 四、政策法规与合规

### 4.1 数据合规要求
- 《个人信息保护法》：用户行为数据属于敏感信息，需明示同意
- 《数据安全法》：数据跨境传输需安全评估
- **Lagom 策略**：默认本地存储，云端同步需用户主动开启，全程端到端加密

### 4.2 AI 服务合规
- 生成式 AI 服务需备案（《生成式人工智能服务管理暂行办法》）
- AI 对话内容需符合社会主义核心价值观
- **Lagoom 策略**：接入国内备案模型（DeepSeek、Qwen），避免使用未备案模型

### 4.3 应用商店合规
- App Store / 国内应用商店对"锁机""限制其他 App"功能审核趋严
- **Lagom 策略**：专注期间限制功能采用"系统级提醒"而非"强制拦截"

## 五、市场机会总结

### 5.1 机会窗口

1. **品类空白**：国内尚无"AI 情感陪伴 + 自律养成"的头部产品
2. **技术成熟**：端侧 LLM + 云端 API 的成本和性能已达标
3. **用户觉醒**：传统打卡工具用户大量流失，寻求新解决方案
4. **成本优势**：独立开发者可借助 AI 辅助开发，大幅降低开发成本

### 5.2 成功关键因素

| 因素 | 权重 | Lagom 策略 |
|------|------|-----------|
| AI 对话质量 | ★★★★★ | 优质 prompt 工程 + 长期记忆 + 情感化回复 |
| 用户留存 | ★★★★★ | 伙伴亲密度系统 + 微习惯降低门槛 |
| 隐私保护 | ★★★★☆ | 默认本地 + 端到端加密同步 |
| 冷启动体验 | ★★★★☆ | 首次对话即建立情感连接 |
| 付费转化 | ★★★☆☆ | 免费层足够好用，付费层提供深度价值 |

### 5.3 一句话市场判断

> "自律 App 市场正处于从'工具时代'向'AI 伙伴时代'的转折点。谁先做出'真正懂你、陪你成长'的产品，谁就能定义新品类。"

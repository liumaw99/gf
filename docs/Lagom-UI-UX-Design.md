# Lagom UI/UX 设计规范

> 设计理念：温暖、陪伴、减压、非效率工具  
> 目标情感：像和一个真正关心你的朋友相处

---

## 一、设计原则

### 1.1 核心原则

| 原则 | 说明 | 反面示例 |
|------|------|----------|
| **温暖优先** | 每个界面都应该让人感到被关心 | 不要使用冷灰色、锐利边框、机械字体 |
| **对话优先** | 打开 App 第一眼是伙伴，不是任务 | 不要打开就是待办列表或数据统计 |
| **少即是多** | 减少选择焦虑，每天只展示一件事 | 不要展示"10个待办"让用户 overwhelmed |
| **容错友好** | 失败不是错误，是重新了解用户的机会 | 不要用红色、警告图标、"连续失败X天" |
| **正向反馈** | 每个小行动都有温暖的回应 | 不要只记录完成，没有任何反馈 |

### 1.2 与效率工具的差异

```
效率工具的设计：
- 冷色调（蓝、灰、绿）
- 直线、锐角、网格
- 数据、图表、进度条
- 催促感："还有3项未完成"
- 竞争性：排名、徽章、 streak

Lagom 的设计：
- 暖色调（橙、米、柔粉、淡黄）
- 圆角、有机曲线、手绘感
- 故事、成长、伙伴
- 陪伴感："我在这里陪你"
- 支持性："慢慢来，没关系"
```

## 二、色彩系统

### 2.1 主色调

```
Lagom Orange (品牌色)
├── 主色: #F4A261 (温暖橙)
├── 浅色: #FAD7B4 (柔和米色)
├── 深色: #D4823A (深橙)
└── 使用: CTA按钮、重点高亮、伙伴主题色

Lagom Cream (背景色)
├── 主色: #FDF6EC (奶油白)
├── 暗色: #F5E6D3 (暖灰背景)
└── 使用: 页面背景、卡片底色

Lagom Sage (辅助色)
├── 主色: #A8C5A8 (柔和绿)
├── 浅色: #D4E5D4 (淡绿)
└── 使用: 成功状态、完成标记、自然元素

Lagom Blush (情感色)
├── 主色: #E8B4B8 (柔粉)
├── 浅色: #F5E0E2 (淡粉)
└── 使用: 关怀、鼓励、温馨时刻

Lagom Sky (辅助色)
├── 主色: #B4C7E7 (柔和蓝)
└── 使用: 专注场景、冷静时刻
```

### 2.2 语义色彩

| 用途 | 颜色 | 说明 |
|------|------|------|
| 成功/完成 | #A8C5A8 (Sage) | 不是刺眼的亮绿，而是温和的草绿 |
| 进行中 | #F4A261 (Orange) | 温暖的进行中状态 |
| 缓冲日 | #C4A8D4 (柔和紫) | 不完成的休息日，用紫色标记 |
| 信息 | #B4C7E7 (Sky) | 温和的提示信息 |
| 文字主色 | #4A403A (暖深棕) | 不是纯黑，而是温暖的深棕 |
| 文字辅色 | #8B7E74 (暖灰) | 次要信息 |
| 分割线 | #E8DDD0 (暖浅灰) | 柔和的分隔 |

### 2.3 失败/未完成状态设计（关键）

```
传统设计：
❌ 红色背景 + 警告图标 + "未完成"
❌ 连续天数归零，显示"0"

Lagom 设计：
✅ 当天格子保持空白或用浅灰色点
✅ 不显示任何"失败"字样
✅ 伙伴会 gentle 地说："昨天没来得及吗？没关系，今天慢慢来"
✅ 缓冲日用柔和的紫色小月亮标记
```

## 三、字体系统

### 3.1 字体选择

| 用途 | 字体 | 备选 |
|------|------|------|
| 标题 | 系统默认 + 字重调整 | iOS: SF Pro Display, Android: Roboto |
| 正文 | 系统默认 | iOS: SF Pro Text, Android: Roboto |
| 伙伴对话 | 圆润字体 | 使用系统默认但加大字间距，增加呼吸感 |
| 数字/数据 | 系统默认 | 避免等宽字体，保持温度 |

### 3.2 字号规范

```
Display:    32px / 粗体  → 大标题（如"早上好"）
Heading 1:  24px / 粗体  → 页面标题
Heading 2:  20px / 中粗  → 卡片标题
Heading 3:  18px / 中粗  → 小节标题
Body Large: 16px / 常规  → 伙伴对话正文
Body:       14px / 常规  → 普通正文
Caption:    12px / 常规  → 辅助说明、时间戳
```

### 3.3 对话特殊排版

```
伙伴消息：
- 字间距: +0.5px
- 行高: 1.6
- 每条消息最大宽度: 80%
- 圆角: 左 20px, 右 20px, 右下 4px（像说话气泡）
- 背景: #FFFFFF（白色卡片）
- 阴影: 极浅的暖色阴影

用户消息：
- 对齐: 右侧
- 背景: #F4A261（品牌橙，浅色版）
- 圆角: 左 20px, 右 20px, 左下 4px
```

## 四、组件规范

### 4.1 按钮

```
【主按钮】
- 背景: #F4A261 (Lagom Orange)
- 文字: #FFFFFF
- 圆角: 24px (全圆角，药丸形)
- 高度: 52px
- 阴影: 0 4px 12px rgba(244, 162, 97, 0.3)
- 按下态: 背景变深 #D4823A, 阴影缩小
- 使用: "完成"、"开始专注"、"和伙伴聊聊"

【次按钮】
- 背景: 透明
- 边框: 1px solid #F4A261
- 文字: #F4A261
- 圆角: 24px
- 高度: 48px
- 使用: "换个"、"晚点"、"跳过"

【文字按钮】
- 背景: 透明
- 文字: #4A403A，下划线
- 使用: "查看更多"、"编辑"

【禁用态】
- 背景: #E8DDD0
- 文字: #8B7E74
- 不使用品牌色，避免"强制感"
```

### 4.2 卡片

```
【今日任务卡片】
- 背景: #FFFFFF
- 圆角: 20px
- 阴影: 0 2px 16px rgba(74, 64, 58, 0.08)
- 内边距: 20px
- 顶部装饰: 4px 高的品牌色条
- 图标: 左侧圆形背景 + 图标

【对话消息卡片】
- 背景: #FFFFFF
- 圆角: 20px（根据方向调整）
- 无阴影（对话流中阴影会杂乱）
- 内边距: 12px 16px

【统计卡片】
- 背景: 渐变（从 #FDF6EC 到 #F5E6D3）
- 圆角: 16px
- 无边框
- 使用: 成长报告、数据展示
```

### 4.3 输入框

```
【聊天输入框】
- 背景: #FFFFFF
- 边框: 1px solid #E8DDD0
- 圆角: 24px
- 高度: 自适应（多行）
- 占位符: "和伙伴聊聊..."（灰色，非催促性）
- 左侧: 语音按钮 🎙️
- 右侧: 发送按钮（品牌色，仅输入内容后激活）

【表单输入框】
- 背景: #FDF6EC
- 边框: 无（底部 1px 线）
- 聚焦态: 底部线变为品牌色
- 标签: 上方浮动标签
```

### 4.4 图标

```
风格: 线性图标（outline），圆角端点，2px 线宽
- 不使用尖锐的箭头，使用柔和的曲线
- 不使用纯功能图标，适当添加情感化小装饰

常用图标:
- 完成: ✓（柔和的圆圈内）
- 习惯: 🌱（萌芽，而非打勾）
- 专注: 🎯（靶心，而非时钟）
- 设置: ⚙️（柔和齿轮）
- 伙伴: 根据选择的形象动态变化
```

## 六、动画与动效

### 6.1 原则

| 场景 | 动效风格 | 时长 |
|------|----------|------|
| 页面切换 | 柔和的淡入 + 轻微上移 | 300ms |
| 消息出现 | 从底部弹入 + 弹性缓动 | 250ms |
| 完成任务 | 小星星/花瓣飘散 + 伙伴跳跃 | 800ms |
| 伙伴互动 | Lottie 循环动画（眨眼、摇尾巴） | 无限 |
| 加载状态 | 伙伴"正在思考"的可爱动画 | 直到完成 |
| 失败/跳过 | 无特殊动效（不强调） | 0ms |

### 6.2 关键动画

```
【完成动画】
用户点击"完成"后：
1. 按钮变为 "✓ 已完成"，颜色变为 Sage 绿
2. 从按钮位置飘出 5-8 个小星星/花瓣
3. 伙伴头像播放"开心"动画（Lottie）
4. 如果这是当天的第一个完成，伙伴发送消息："今天的第一件小事完成啦！太棒了～"

【伙伴思考中】
用户发送消息后，等待 AI 回复时：
1. 伙伴头像下方显示「...」跳动
2. 或伙伴做出"思考"的小动画（挠头、托腮）
3. 不使用冰冷的 loading spinner

【家园生长】
HSI 提升时：
1. 对应的元素播放生长动画
2. 树：从小苗→小树→大树
3. 小溪：从干涸→细流→小河
4. 配合柔和的环境音效（V2）
```

## 七、语音交互设计（V2）

### 7.1 语音输入

```
用户长按 🎙️ 按钮：
- 按钮放大，出现波纹动画
- 屏幕显示「我在听...」
- 实时显示语音转文字（逐字出现）
- 松开发送

语音识别错误时：
- 不显示"识别失败"的错误提示
- 显示识别结果，用户可点击编辑
- 伙伴回复："你说的是...对吗？"
```

### 7.2 语音输出

```
伙伴语音特征：
- 温柔、不紧不慢的语速
- 适当的停顿和语气词
- 短句优先（不超过 20 秒）

用户可控制：
- 全局开启/关闭语音
- 仅特定时段开启（如晚上）
- 语速调节（0.8x - 1.2x）
```

## 八、响应式与适配

### 8.1 屏幕适配

```
手机（主要）:
- 375pt - 430pt 宽度
- 底部 Tab Bar 导航
- 全屏页面切换

平板（后续）:
- 左侧固定伙伴对话区
- 右侧内容区（习惯/专注/成长）
- 类似 iPad 邮件应用的分栏设计
```

### 8.2 深色模式（V2）
